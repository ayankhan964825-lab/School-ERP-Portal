# Future Enhancements & Backlog

This file tracks features, UI improvements, and integrations that are dependent on multiple core modules being completed first, or are "nice-to-have" polish items that shouldn't block the MVP.

## 1. 360-Degree Student Profile (Student 360 View)
**Current Status:** Simple modal with basic edit/view for name, phone, and status.
**Future Goal:** Upgrade to a full-page dashboard that aggregates data from all modules:
- **Documents:** Visual checklist of submitted vs pending documents (Aadhar, TC, etc.)
- **Attendance:** Calendar heatmap showing presence, absence, and leaves.
- **Fees:** Mini-ledger showing total paid, pending dues, and payment history.
- **Academics:** Charts showing exam performance across the session.
- **Transport/Hostel:** Assigned bus route, stop timings, and hostel room.
**Dependencies:** Requires Attendance, Fees, Exams, and Transport modules to be fully built and populated.
